# Projet Boutique

Bienvenue dans le projet Boutique ! Ce dépôt contient le code source et la documentation pour une application Java conçue pour gérer l'inventaire, les ventes et les interactions avec les clients d'une boutique.

## Fonctionnalités

- **Gestion de l'inventaire** : Ajouter, mettre à jour et supprimer des produits.
- **Suivi des ventes** : Enregistrer et surveiller les transactions de vente.
- **Gestion des clients** : Maintenir les informations des clients et l'historique des achats.
- **Interface conviviale** : Design simple et intuitif pour une utilisation facile.

## Prérequis

- Java Development Kit (JDK) 11 ou supérieur
- Un éditeur de code ou IDE (par exemple, IntelliJ IDEA, Eclipse)
- Maven (optionnel, pour la gestion des dépendances)

## Démarrage

1. Clonez le dépôt :
    ```bash
    git clone https://github.com/your-username/boutique.git
    ```
2. Accédez au répertoire du projet :
    ```bash
    cd boutique
    ```
3. Compilez et exécutez l'application :
    ```bash
    javac Main.java
    java Main
    ```
